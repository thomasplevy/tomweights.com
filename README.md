tomweights.com
==============

This repository houses the code for my personal website [tomweights.com](https://tomweights.com).

The site is built with [Eleventy](https://www.11ty.dev/) and hosted on GitHub Pages.

## Local development

```bash
npm install
npm start
```

The site is served at [http://localhost:8888](http://localhost:8888).

```bash
npm run build
```

writes the static site to `_site/`.
